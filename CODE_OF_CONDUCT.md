# Community Code of Conduct

## Our Commitment

We are dedicated to providing a welcoming, constructive, and harassment-free community for everyone participating in the **Software Update Manager** project, regardless of technical background, experience level, identity, or hardware configuration.

## Expected Standards

Community members and contributors are encouraged to:
- **Demonstrate Empathy & Respect:** Engage in thoughtful, courteous dialogue when opening issues, reviewing pull requests, or requesting features.
- **Focus on Constructive Collaboration:** Provide actionable feedback centered on code correctness, security, performance, and user safety.
- **Respect User Trust & Safety:** Remember that users run this utility with Administrator privileges to keep their PCs healthy and secure. Code safety and integrity always come first.
- **Accept Constructive Criticism Graciously:** Value diverse technical perspectives and work toward consensus.

## Unacceptable Behavior

The following behaviors will not be tolerated in any project space:
- Harassment, insulting remarks, derogatory comments, or personal attacks.
- Publishing private information of others without explicit authorization.
- Promoting malicious software, exploits, or unvetted bundles within issues or pull requests.
- Sustained disruption of issues, discussions, or development channels.

## Enforcement Responsibilities

The project maintainers are responsible for clarifying and enforcing these standards. Maintainers have the right to edit, close, or remove issues, comments, or pull requests that do not align with this Code of Conduct.

## Reporting Concerns

If you experience or observe unacceptable behavior within this project, please reach out directly to the project maintainers via GitHub or project channels. All reports will be reviewed promptly and handled with discretion.
